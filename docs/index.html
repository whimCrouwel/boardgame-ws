server.ts
import { GameServer } from 'boardgame-ws'

const server = new GameServer({
  maxPlayersPerRoom: 4,
  maxRooms: 10,
  reconnectGraceMs: 120_000,
})

const port = await server.listen(8080)
console.log(`ws://localhost:${port}`)

server.on('roomCreated', (code) => {
  console.log(`room: ${code}`)
})

server.on('playerJoined', (code, id) => {
  console.log(`joined: ${code}/${id}`)
})

Features

マルチプレイヤーに必要なものがぜんぶ入ってる

ゲームロジックは一切なし。トランスポートとルーム管理だけに徹したシンプルな設計です。

🚪

ルーム管理

6 文字の参加コードで友人を招待。ホスト権限付きで room.lock · room.kick も使えます。

🔢

順序保証

全ブロードキャストにルーム固有の連番 seq を付与。メッセージの欠落・重複なしで届きます。

💾

スナップショット

任意の状態 BLOB をサーバーに保存。途中参加・再接続時に即座にキャッチアップできます。

🔄

再接続リカバリー

セッショントークンで切断後 2 分間（設定可）座席を確保。ネットワーク障害でゲームが止まりません。

👥

プレゼンス通知

join / leave / disconnect / reconnect / kick をルーム全員にブロードキャスト。

🎲

ゲーム非依存

ペイロードは完全に不透明。三目並べでも将棋でもカードゲームでも、任意の JSON を中継するだけ。

Wire Protocol

シンプルな JSON プロトコル

クライアント SDK は不要。ws を使えばどんな言語からでも接続できます。詳細は PROTOCOL.md を参照。

クライアント → サーバー
hello接続・セッション開始（nickname・token）
room.createルーム作成。作成者がホストになる
room.join参加コードでルームに参加
move任意ペイロードをブロードキャスト
snapshot.set状態 BLOB を保存（ホスト推奨）
sync.requestスナップショット＋差分を再送要求
chatテキストチャット
room.lock / unlockルームの施錠（ホスト専用）
room.kickプレイヤーをキック（ホスト専用）
サーバー → クライアント
welcomeplayerId · token を返却
ack / errorリクエスト成功・失敗
room.createdルーム作成完了（作成者のみ）
room.joined参加完了（参加者に送信）
moveゲームアクション（全員にブロードキャスト）
snapshot参加・再接続時の状態スナップショット
presence入退室・切断・再接続通知
chatチャットメッセージ
room.closedルームが閉じられた通知
Quick Start

3 分で動かせる

Node.js 18 以上と ESM プロジェクト（"type": "module"）があれば始められます。

1

インストール

npm でインストール。ws 以外の依存関係はありません。

npm install boardgame-ws
2

サーバーを起動

GameServer を作って listen() を呼ぶだけ。

import { GameServer } from 'boardgame-ws'

const server = new GameServer({ maxPlayersPerRoom: 4 })
await server.listen(8080)
// ✓ ws://localhost:8080
3

クライアントから接続

WebSocket で接続して hello を送信。welcome でセッション ID とトークンが返ります。

const ws = new WebSocket('ws://localhost:8080')
ws.send(JSON.stringify({ type: 'hello', reqId: 1, nickname: 'Alice' }))
// ← { type: 'welcome', playerId: 'p_...', token: '...' }
4

ルームを作ってゲーム開始

ホストが room.create、友人が room.join。あとは move でゲームアクションを送るだけです。

// ホスト側
ws.send(JSON.stringify({ type: 'room.create', reqId: 2 }))
// ← { type: 'room.created', code: 'XKJF92', members: [...] }

// 参加者側
ws.send(JSON.stringify({ type: 'room.join', reqId: 1, code: 'XKJF92' }))
